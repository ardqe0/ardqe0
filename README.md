# Ardqe

ASP.NET Core, Blazor, React ve React Native ile güvenli web ve mobil uygulamalar geliştiriyorum.

## Hakkımda

.NET ekosistemi ve modern JavaScript teknolojileriyle uçtan uca uygulamalar geliştiriyorum. Backend güvenliği, gerçek zamanlı sistemler, mobil istemciler ve yönetim panelleri üzerine çalışıyorum.

## Öne çıkan projeler

| Proje | Açıklama | Teknolojiler |
| --- | --- | --- |
| [RestaurantApp](https://github.com/ardqe0/RestaurantApp) | QR sipariş, gerçek zamanlı mutfak takibi ve yönetim raporlarını birleştiren restoran otomasyonu | ASP.NET Core, React, React Native, SignalR, SQL Server |
| [DeviceService](https://github.com/ardqe0/DeviceService) | Telefon ve elektronik cihaz servisleri için web, Windows ve Android destekli servis takip sistemi | .NET 10, Blazor, .NET MAUI, SQL Server |
| [Knitting Shop](https://github.com/ardqe0/knitting-shop) | El örgüsü ürünlerin listelenmesi ve yönetilmesi için geliştirilen e-ticaret uygulaması | .NET 8, ASP.NET Core MVC, Entity Framework Core, SQL Server |
